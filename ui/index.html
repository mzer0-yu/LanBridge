      HTTP API
      本机 / 公网
      通过 HTTP 请求管理，无需项目文件。
      接口与认证
      • POST /api/login：管理员登录，获得会话 Cookie 和 csrf。
      • GET /api/state：查看网站、缺少的配置和连接器状态。
      • POST /api/sites：保存网站与策略，自动发布所需路由变更。
      • POST /api/connector/ensure：检测 / 下载连接器。
      • POST /api/cloudflare/preview → apply：预览，再提交 revision 发布。
      所有 POST 需带 Origin；登录后的 POST 还需会话 Cookie 和 X-CSRF-Token。公网接入还需完成入口访问验证。
      本机 Python 示例
      import getpass
import httpx

base = "http://127.0.0.1:8890"
with httpx.Client(base_url=base, headers={"Origin": base}) as client:
    login = client.post("/api/login", json={
        "username": input("管理员用户名："),
        "password": getpass.getpass("管理员密码：")
    })
    login.raise_for_status()
    client.headers["X-CSRF-Token"] = login.json()["csrf"]
    state = client.get("/api/state")
    state.raise_for_status()
    print(state.json()["cloudflare_setup"])
      

      MCP
      本机 AI 工具
      让 AI 客户端调用 LanBridge 管理工具。
      客户端配置
      启动 LanBridge，再将以下配置添加到支持 MCP 的客户端。
      {
  "mcpServers": {
    "lanbridge": {
      "command": "<项目目录>/.venv/Scripts/python.exe",
      "args": ["<项目目录>/mcp_server.py"]
    }
  }
}
      将项目目录替换为实际绝对路径。
      • 通过客户端安全环境配置提供 LANBRIDGE_ADMIN_USERNAME 和 LANBRIDGE_ADMIN_PASSWORD，不把真实密码写进项目文件。
      • 可选 LANBRIDGE_ADMIN_URL 指定本机管理地址；默认端口 8890。现有 MCP 不支持公网地址。
      • 常用工具：lanbridge_status、lanbridge_save_site、lanbridge_prepare_connector、lanbridge_preview、lanbridge_apply。
