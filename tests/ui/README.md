# 隔离浏览器检查

在项目目录运行 `node tests/ui/run.cjs`。需要 Node.js、Playwright 和已安装的 Microsoft Edge；本次验证使用 Playwright 1.62.1。未安装 Playwright 时可运行 `npm install --no-save --package-lock=false playwright@1.62.1`，无需下载额外浏览器。

这些检查通过 `page.route` 拦截全部 `lb.preview` 请求，使用 `fixture.js` 中的虚构配置，不连接正式 Cloudflare 账户，不读取 `data/`，也不修改正式网站或凭据。脚本可以从任意工作目录运行。

覆盖六个页面、网站编辑、登录切换和失败反馈、临时授权、复制和撤销、日志分页和展开、导航定位、桌面及手机溢出，以及 HTML 文本转义。`disclosure-style-check.js` 检查全部 27 个静态折叠项及动态日志详情的标题边框、展开前后尺寸、相对位置、字体与间距，并检查 6 个按钮控制的展开区域；包含隐藏分支、嵌套账户配置、令牌管理、自定义路径和密钥区域。截图统一写入项目 `.test-artifacts/ui/`，不提交到 Git。

浏览器检查补充后端和 Node 测试，不代替真实公网部署验收。API 返回值、鉴权和资源限制由 Python 测试验证。

`aliyun-connected-domains-check.js` 覆盖当前阿里云持有且已接入的域名清单、最近已完成任务移至日志折叠入口、刷新失败保留已标注的旧结果，以及退出登录后的迟到查询；使用模拟 yuboyi.me 和 mobomicro.com，核对 320/390/1440px。`auto-tunnel-setup-check.js` 验证授权已保存后的自动配置进度、失败恢复及完成提示，恢复不重新发起浏览器授权。统一入口当前为 35 组隔离浏览器检查。`paused-page-check.js` 使用真实 Python 暂停页面渲染器，检查手机、桌面、长域名、名称不泄露和键盘刷新。

`visitor-verification-check.js` 直接生成隔离的网关验证页面，拦截验证 API 和 Cloudflare 脚本；覆盖 320、390、760、1440px、长名称、空响应、重新验证、脚本加载失败及不支持 `AbortSignal.timeout` 的浏览器。窄屏使用官方 compact 尺寸，模拟组件验证布局，不操作真实 Turnstile 或正式网站。

刷新检查涵盖快速重复点击、动画与成功反馈、失败重试及尺寸稳定；HTTP 默认接入的重复脚本已合并进导航检查，统一入口当前运行 35 组浏览器检查，包含登录初始化、公网转发列表开关及关闭提示页。

全页面布局检查额外覆盖 760px 和 900px，检查移动端/桌面转换处的排版；全部宽度为 1440、900、760、390px。

`content-layout-check.js` 补查 320、760、1440px 下的长网站名称、长地址及表单字体一致性；转发列表额外覆盖 320、390、760、1440px，检查长文本、统一刷新按钮尺寸、暂停网站链接和溢出。令牌值保留等宽字体。

网关恢复检查覆盖启动失败提示、重试后的状态刷新，以及桌面和手机布局；后端运行测试使用真实被占用端口验证管理台保持可用和在线恢复。

`autofill-check.js` 使用已安装 Chrome 的隔离配置文件，验证九处配置密钥控件的遮罩/表单关联、非登录表单自动完成设置、真实登录密码语义、同值事件与编辑还原、回车提交及无隐式写请求。不读取用户 Chrome 密码库；此检查不声称覆盖真实已保存密码触发和第三方密码管理扩展。

`domain-onboarding-check.js` 检查新增域名接入在桌面/手机的预览、密钥遮罩与清空、显式确认、记录值转义、登录代次及公网/临时令牌隐藏。仅模拟 API，不改真实域名。

`oauth-renewal-check.js`：桌面/手机管理授权续期提示、手动重试及成功后清除，使用模拟 API。

`permission-recovery-check.js` 验证 OAuth 错误面板不显示令牌修复入口、域名创建失败定位原操作，以及凭据更新后的历史记录说明，覆盖桌面与手机。

`browser-switch-check.js` 验证授权等待中默认浏览器切换 Chrome 时重新发起请求，切换期间锁定控件，覆盖桌面与手机。

折叠布局检查覆盖 1920/1440/1100/900/760/390/320px，同级两个配置折叠项覆盖四种展开组合；1440px 经典滚动条场景验证页面开始滚动时卡片列宽与横向位置不变。阿里云接入任务布局覆盖 320/390/760/900/1440/1920px，核对预览、等待、结果待核验和失败状态下的 12px 内容间距。

`human-memory-policy-check.js` 覆盖旧网站一天默认值、保存三十天记忆期、独立短会话时长和 320/390/1440px 编辑器布局；通过模拟 API 保存，不更改正式网站。

`visitor-protection-check.js` 覆盖总览防护统计、验证接口 Retry-After 倒计时和限制页面，核对 320/390/1440px、等待期间禁止提交、结束后不自动重试；使用模拟时钟和接口。

`cloud-pause-check.js` 检查默认本机暂停、可选云端阻断、取消不写入、后台状态、失败重试与恢复，在 320/390/1440px 核对弹窗和错误布局；全部使用模拟接口，不操作正式规则。

暂停编辑布局额外检查处理中提示与按钮垂直对齐、失败详情展开、整个状态标签点击定位，以及处理中/失败/完成时网站行高一致。全部使用模拟接口，覆盖 320/390/1440px。

`checkbox-alignment-check.js` 检查全部 15 个复选框标签，覆盖 320/390/760/1440px：复选框与首行文字中心对齐、两行权限说明、窄屏文字换行、统一尺寸和无横向溢出。

自动云端阻断的纯检测及后端集成见 `tests/test_paused_traffic.py`：连续两个完整窗口、异常门槛、未暂停/未发布/本机直连不触发、HTTP/WebSocket 与入口过载、一次尝试跨重启、恢复竞态、数据库回滚和异步规则核验。全部使用隔离数据及模拟 Cloudflare；不对正式网站制造攻击流量。

`adaptive-human-check.js` 覆盖新建默认按需验证、旧网站保持始终验证、保存重开、开关及 320/390/1440px 布局，全部使用模拟 API。

逐网站防护统计检查沿用 `visitor-protection-check.js`，覆盖默认折叠、网站分组、零计数、长名称/域名、刷新保持展开与更新数字、历史汇总说明，以及受限账号隐藏整个统计区域；截图宽度为 320、390、1440px。

网站统计现含最近 24 小时页面访问、平均每小时与独立 IP，沿用上述桌面/手机分组检查，六项计数在窄屏分两行显示。后端 `test_traffic_metrics.py` 验证口径、IP 去重/最后访问过期、容量下限、恢复、原子保存失败重试和异常存储。

`visual-readability-check.js` 对六页及添加网站弹窗的桌面/手机实际渲染做对比度检查，共 14 个场景，包括网站防护展开表格及未填输入框的 ::placeholder；透明颜色逐层合成背景，占位伪元素透明度也纳入计算。禁用、渐变/图片背景和祖先透明度不在自动断言范围，仍需视觉检查；输出 `.test-artifacts/visual-readability.json`，不声称全站无障碍合规。

静态托管：`static-hosting-check.js` 检查主页文件 URL 识别、协议恢复、保存/重开和 320/390/1440px 布局。

Client 品牌与刷新：`client-refresh-layout-check.js` 检查说明实际间距和对比度、断点两侧、焦点保留、异常响应恢复及空/暂停/静态状态。
