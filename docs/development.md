# LanBridge 1.1.0-dev

当前 `dev` 分支为最新开发版，版本号见根目录 `VERSION`。此版本同步源码，不创建 GitHub Release，不覆盖已有 v1.0.0 标签或下载包。

## 本轮开发内容

- 阿里云账户浏览器授权及手动接入、当前账户持有且已接入的域名列表、域名预览与显式 DNS 切换。
- Cloudflare 授权后的隧道自动配置、部分失败恢复、授权状态和历史错误提示整理。
- 多域名网站编辑、根域名转发、默认域名管理和网站保存后后台发布。
- 手机访问验证的异常响应处理、跨会话异步结果隔离与配置界面间距统一。
- 受控自动重载、减少重复状态刷新及请求内配置快照、旧测试产物归档。
- 人类验证默认记住浏览器一天，跨网络保持有效；无变化或纯名称保存不撤销凭证，异常仍优先限制并持久撤销旧凭证。
- 网页/API 与静态资源独立额度，实际剩余限流时间及验证服务繁忙倒计时、访问防护统计。
- 公网日志只读、本机容量调整、统一重复提交拦截，以及验证 Site Key/Secret Key 一次原子保存。

## 使用与验证

开发版从仓库获取源码，安装及运行步骤见 [README](../README.md)。已有正式 Release 下载包属于 v1.0.0；需要上述开发内容时使用当前源码。

同步前最新完整 Python 489 项、Node 98 项和全部 30 组隔离浏览器检查通过；最终原子保存改动后再次核对网站管理界面。两组启动器检查沿用前轮结果，本次未修改启动器。测试使用隔离数据及模拟上游，不等同于真实 Cloudflare、DNS 和手机网络的端到端验收。当前检查结果与边界见 [检查状态](review-status.md)。

运行数据、密钥、依赖、测试截图及项目外 trash 归档不纳入 GitHub 同步。
