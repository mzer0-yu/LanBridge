## 当前结论

本轮发布前检查未发现新的已确认业务或权限缺陷。完成有依据的效率调整、转发列表样式精简及文档整理；测试结果只代表已检查范围，不保证所有部署场景绝对无 bug。本次 v1.0.0 发布包含启动器、端口、自动连接及后续界面改进；正式服务未停止或重启。

- 启动器增加按用户会话和项目目录区分的窗口锁：同目录重复打开请求唤回已有窗口，不同目录独立打开。跨进程的路径规范化、唤回信号、正常退出及异常退出恢复检查通过，既有操作与布局检查通过；未以自动检查证明真实桌面一定获得前台焦点。布局和服务生命周期未改。

- 启动器检测改为后台辅助进程与界面定时器读取；延迟/无效结果/超时、既有实例操作与复制菜单的隔离检查通过，布局未改。新增发布工具 9 项检查通过，详细指标与打包方法见 [性能测量与本地打包](performance-and-release.md)。

- 发布前完整 Python 回归 318 项通过。保留既有 Starlette/TestClient 弃用警告，本轮未升级依赖。
- Node 62 项、15 组隔离浏览器及启动器检查通过。展开/收起、移动断点、长名称/地址、间距、控件字体和尺寸、登录及保存反馈均有覆盖；转发列表补查 320/390/760/1440px。
