# LanBridge 当前检查状态

更新日期：2026-10-11。开发与运行规则见项目根目录 `AGENTS.md`。

## 当前结论

新增本机静态目录托管：转发目标可填写主页 `file:///` URL，主页所在目录提供静态资源，沿用访问防护、暂停和滚动统计。目录配置限本机完整管理员，公网列表隐藏本地路径，文件边界拒绝越界、私有目录、隐藏文件及链接。无需新增目标选择控件；静态目标自动使用 HTTP，API 未传协议时也不会继承旧 WebSocket。已有静态主页缺失时仍可停用或修改停用名称；新增目录和重新启用继续检查文件。

账户授权、隧道自动配置、阿里云域名接入和网站后台发布沿用现有权限及数据保护边界。域名迁移必须预览并明确确认 DNS 切换；已接入列表只显示当前阿里云账户持有且已接入 LanBridge 的域名。有效网站关联会阻止移除域名。

Cloudflare 浏览器授权保存后自动配置专用隧道，部分失败可继续；未知创建结果先核对原任务，重启后可恢复，账户或凭据变化会拒绝旧任务。隧道连接作为维护入口，已配置时无需操作。授权成功提示仅属于当前页面操作，历史失败保留详情与时间。

跨会话异步结果不得覆盖当前输入、反馈或开始下一次写入。网站保存使用后台发布；公网验证保留 HTTPS、策略、限速和服务端令牌校验。人类验证默认独立记住当前浏览器 1 天（0–30 天可配），不随 IP 变化重复验证；网站口令仍按短会话核验。只改名称或无变化保存不使访问凭证失效。访问策略变化继续撤销凭证。异常优先按有效凭证绑定的浏览器累计，缺少标识时按 IP；换网不清空，同 IP 已验证浏览器分开处置，新验证保留短期 IP 限制。静态资源独立四倍额度，网页/API 使用配置额度，IP 总额度和全局资源保护继续执行。验证页及受限浏览器导航显示倒计时，总览提供完整管理员可见的最近 24 小时滚动防护统计。异常行为优先于记忆：持续限流拒绝、批量敏感路径探测、实际验证失败和访客 WebSocket 资源违规触发 5–15 分钟限制并持久撤销旧凭证；限制期间不能重新验证绕过，签发与处置互斥。新增“仅异常时验证”：正常低频直通、网页/API 及 WebSocket 新连接高频时触发，静态资源独立；旧网站保留始终验证，新建界面默认按需验证。口令会话明确区分是否通过人类验证，避免伪造记忆。按需模式的匿名 HTTP/静态资源/API 与 WebSocket 均执行来源短期冷却，清除 Cookie 不能绕过；其他有效凭证的浏览器独立处置。无有效口令或人类验证的空提交不签发短会话，历史空会话不参与身份/异常归属。请求内复用验签解析结果，实时重查绑定、过期与撤销；WebSocket 周期检查重新验签。

表单采用共同提交拦截，保存中即使按钮因刷新重新启用，也不再次提交；账户登录沿用表单锁。验证服务繁忙的 503 Retry-After 也显示等待倒计时。Site Key 与 Secret Key 一次原子保存，与凭证失效共同提交，失败回滚；部分设置保留其他现有字段，临时令牌不获验证凭据写权限。

公网完整管理员只可查看和下载操作日志，所有日志写操作由后端统一拒绝；日志容量仅本机完整管理员可调整，转发头不能绕过。拒绝事件限频记录，防止请求刷满日志；既有超限自动清理规则仍保留。

状态接口将设置、网站、凭据是否存在与接入就绪状态统一为一次请求内的配置快照。部分配置操作去除成功或失败后的第二次状态刷新；不增加长期密钥缓存，不复用变更前尚未完成的状态请求。

已暂停且已发布的网站在连续两个完整分钟均达到高频与异常阈值时，后台尝试精确域名云端阻断；每轮暂停仅自动尝试一次，失败仍保持本机暂停。恢复转发时核验解除原规则；完整管理员权限与有效 WAF 授权仍是云端操作的前提。暂停提交的权限检查和状态变更共用服务锁。
