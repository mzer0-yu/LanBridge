- 声明长度的下载可能无限占用暂存磁盘。现在单个 256 MiB、合计 512 MiB 预留额度，慢速消费者仍占用额度；接收最多 300 秒，保留原始字节长度检查。大于单个上限的下载会被拒绝，这是兼容性限制；调整部署规模前需评估磁盘和带宽。
- 每身份限流队列会随请求数增长，且身份轮换会驱逐活跃记录。现在固定窗口计数器保持常量空间，达到身份容量时拒绝新身份，避免清空仍有效的限额。
- scrypt 口令校验原先在事件循环运行。现在在线程中执行，并由验证并发上限限制同时执行数。DNS、socket 和暂存操作使用不会在取消后继续无人管理的等待方式。
- 上游连接建立期间取消原先缺少客户端关闭保障。现在关闭受到取消屏蔽保护；暂存写入完成后才能清理文件，避免后台写入与关闭竞争。
- 浏览器 WebSocket 原先接受任意 Origin。现在拒绝跨站 Origin，保留无 Origin 的程序客户端及其访问策略校验；发送有阻塞期限，收消息队列有上限。

数值和拒绝行为详见 README 的部署限制。额度按单个网关进程计算，增加进程会相应放大总额度。

## 鉴权边界

来源：security-review.md。

现有代码及回归检查没有发现直接绕过真人验证、访客口令或管理员登录的路径。Cookie 签名绑定网站、域名、IP、策略版本和有效期；Turnstile 服务端检查 success、hostname 和 action。管理员监听 loopback，检查 Host、Origin、会话和修改请求的 CSRF。

普通网站源站 DNS 在连接前校验并固定局域网 IP，禁止公网、链路本地地址与本平台端口。HTTP 重定向不由代理自动追随；客户端不能指定任意源站。客户端转发头被清理，HTTPS 保持证书校验。只有 loopback 连接的 Cloudflare 访客头被信任。

本机其他进程与当前 Windows 用户属于信任边界：能连接网关的本机进程可以伪造 Cloudflare 访客头；拥有当前用户权限的恶意程序也能访问该用户的凭据。不要把网关改为监听公网，不能把 IP/国家限制视为对本机恶意程序的防护。

## 尚存的运行限制

来源：security-review.md。

- 有限的并发配额仍可被占满；这是资源止损而非可用性保证。长期 WebSocket/SSE 会占用名额。WebSocket 已限制消息和字节速率，但没有每日字节配额；同一 IP 可建立多条连接，源站仍应限制昂贵业务操作。
- 暂存预算不替代磁盘剩余空间检查；操作系统磁盘不足会导致请求失败并清理暂存。转发和 Uvicorn 运行错误日志已分别轮转（各约 20 MiB），外部启动器捕获的 stdout/stderr 和 CLI 输出仍应设置部署侧保留期限。
- 每请求仍读取本机配置/凭据，数据库与加解密开销尚未单独压测。依赖漏洞扫描、Cloudflare 账户实际 WAF/限流规则核验和多机压力测试不在本次完成范围。
- Turnstile 证明一次验证通过，不等于持续防机器人；验证会话中的访客仍可能滥用源站。不能承诺已“彻底防住 DDoS”。

Cloudflare 的边缘 DDoS 防护承担公网攻击流量过滤，本机限额保护已经进入网关的请求。可核对 [Cloudflare DDoS 防护说明](https://developers.cloudflare.com/ddos-protection/about/) 和 [HTTPX 连接复用说明](https://www.python-httpx.org/async/)。

### 显式远程管理入口

LanBridge 自身入口通过 `target=lanbridge` 显式开启，经过网关的 HTTPS、访问策略和资源限制后进程内分发。远程管理实例只允许启用且未暂停的自身入口主机名，不改变本机管理监听器的 Host/loopback 校验。原普通代理的自身端口阻断继续保留。

远程禁止账户首次初始化、本机登录授权所有接口、Cloudflare 浏览器授权及平台退出；管理操作继续要求管理员会话、同源 HTTPS Origin 和 CSRF。Cookie 仅属当前主机并有 Secure/HttpOnly/SameSite=Strict；远程密码检查移至工作线程，登录按来源及总量限速，管理 JSON 请求读取限制为 20 KB。远程 `/client` 按入口策略开放且包含配置的局域网地址，部署者应据此选择访问策略。
