# LanBridge v1.0.0

让局域网网页拥有自己的公网入口，在一个管理台里完成网站发布、访问保护与连接器管理。

本次更新仍沿用首个正式版本 v1.0.0，包含最新版 Windows 启动器、实例控制、端口管理、自动连接设置与界面改进，采用 MIT 许可证。

## 主要功能

- 多网站、多域名映射，支持 HTTP / HTTPS、WebSocket / WSS。
- Cloudflare Tunnel、DNS 和 Turnstile 配置准备、变更预览、发布及核验。
- 人类验证、可选访问口令、国家/IP 访问策略与请求限速。
- 随时暂停或恢复网站；可单独关闭公网转发列表页面。
- 临时管理令牌按权限和期限授权，支持撤销；操作日志可导出 JSONL。
- 网页、CLI、HTTP API 与 MCP 入口，提供 Agent 启动和实例控制说明。

## 本次更新

- 启动器可检测本机已运行实例，打开管理台、关闭或重启选中实例。
- 同目录只保留一个启动器窗口，重复打开请求唤回；不同安装目录可独立打开。关闭启动器不会关闭后台服务。
- 启动前可修改管理台端口并检测占用；启动后可选择是否打开浏览器。网关端口冲突不阻止进入管理台，可在本机管理台恢复。
- 管理台支持保存下次生效的管理端口，并通过重启应用；重启前检查端口，启动时发生竞争占用会尝试恢复旧端口。
- 连接器提供“启动时自动连接”设置；手动停止后本次运行保持停止，管理台重启保留当前连接器状态。
- 实例检测在后台执行，避免检测等待阻塞启动器；配置密钥使用遮罩控件，改善浏览器自动填充和未保存提示。
- 改善管理台登录闪现、折叠区域、保存和刷新反馈，统一相关控件样式，兼顾桌面和手机。
- 增加本地源码打包、文件清单和 SHA-256 校验工具。

## 安装

下载 `LanBridge-v1.0.0-source.zip`，解压后安装 Python 3.12+，运行 `install.ps1` 安装依赖，再双击 `start.cmd`。

需要 Cloudflare 账户、已接入 Cloudflare 的域名，以及能访问局域网源站的 Windows 电脑。首次启动设置管理员密码，随后按管理台引导配置并发布网站。完整说明见 [使用指南](../user-guide.md)，自动化入口见 [Agent / CLI 说明](../agent-startup.md)。

发布包不包含个人配置、数据库、凭据、cloudflared 二进制、Python 虚拟环境或测试缓存。附带 `manifest.json` 文件清单和 `SHA256SUMS.txt` 校验文件。

## 验证与限制

验证结果见 [当前检查状态](../review-status.md)。主要验收平台为 Windows；这是 Python 源码发行包，需要安装依赖。真实公网长期连接、满载压力和不同安装环境仍需按部署验证，测试通过不等于安全认证。
