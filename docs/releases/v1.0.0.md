# LanBridge v1.0.0

LanBridge 首个正式发布版本：让局域网网页拥有公网入口，并集中管理发布、访问保护和临时协作授权。

本次更新：增加启动前端口选择，改用 MIT 许可证；更新源码包及校验文件，仍归入 v1.0.0。

## 首版功能

- Windows 启动器：启动前可修改管理台和网关端口，管理台端口冲突在启动器重选；网关冲突不阻止登录，可在管理台在线恢复。重复启动会识别同项目实例并打开现有管理台。
- Windows 管理台与本机 cloudflared 连接器管理。
- 多网站、多域名映射，HTTP / HTTPS、WebSocket / WSS 转发。
- Cloudflare Tunnel、DNS 与 Turnstile 配置准备、预览、发布和核验。
- 人类验证、可选访问口令、国家/IP 策略、请求限速。
- 网站暂停/恢复；可选公网管理和可关闭的转发列表页面。
- 有期限、可撤销、按范围授权的临时管理令牌。
- 操作日志容量管理、JSONL 导出，以及 CLI / HTTP API / MCP 接入。
- 桌面和手机布局，原位操作反馈和键盘可访问的主要交互。

## 安装

下载源码 ZIP，解压后用 Python 3.12+ 运行 `install.ps1`，再双击 `start.cmd`。详见 [项目首页](../../README.md)。发布包不包含个人配置、数据库、凭据、连接器、Python 虚拟环境或测试缓存。

## 验证与限制

本次更新完整后端回归：287 项 Python 通过。61 项 Node、13 组隔离浏览器检查通过。启动器另通过 PowerShell 语法、控件实例化与离屏布局检查。主要验收平台为 Windows；首版不是独立 EXE，不默认提供开机自启、完整访客登记或失败登录记录表。真实公网满载、长期连接和不同安装环境仍需按部署验证。
